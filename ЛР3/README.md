# Лабораторная работа №3. Календарь событий

**Тема:** №13 «Календарь событий»
**Студент:** Ельченинов Олег Олегович, группа ИСП 11-51

## Постановка задачи

Разработать консольное приложение «Календарь событий». Программа хранит события
(дата, название, заметка), позволяет добавлять, просматривать, искать и удалять их,
выводить события на выбранную дату и ближайшие события, а также удалять прошедшие.
Данные сохраняются в файл и доступны при следующем запуске.

## Язык и запуск

- Язык: **Python 3.9+** (проверено на Python 3.12). Внешние библиотеки не нужны.
- Запуск из папки работы:

```bash
python src/main.py
```

Путь к файлу данных считается от расположения программы, поэтому запускать
можно и из другой папки: `python ЛР3/src/main.py`.

## Структура


## Формат файла данных

`data/events.json` — JSON-список объектов. Пример записи:

```json
{"date": "2026-11-24", "title": "Защита лабораторной работы", "note": "Принести ссылку на PR"}
```

| Поле    | Тип    | Описание                          |
|---------|--------|-----------------------------------|
| `date`  | строка | дата в формате ГГГГ-ММ-ДД         |
| `title` | строка | название события (не пустое)      |
| `note`  | строка | заметка (может быть пустой)       |

Если файла нет или он пустой, программа начинает с пустого календаря и создаёт
файл при первом сохранении. Файл обновляется после каждого добавления и удаления,
а также при выходе.

## Используемые коллекции

- **`list[Event]`** — основное хранилище. События идут по датам, нужен перебор и
  доступ по номеру, поэтому список подходит лучше всего. Через него реализованы
  добавление (`append` + сортировка по дате), удаление одного события (`pop`),
  удаление прошедших (замена содержимого списка отфильтрованным), поиск и
  фильтрация по дате, периоду и названию (генераторы списков).
- **`dict`** — группировка для вывода: ключ — дата, значение — список событий этого
  дня. Благодаря словарю события одного дня печатаются под общим заголовком с датой.
- **`dict` в главном цикле** — таблица «номер пункта меню → действие» вместо длинной цепочки `if/elif`.
- **`tuple`** — пары `(номер, событие)` в результатах поиска, чтобы номера в них
  совпадали с номерами в полном списке.

Класс `Event` (`dataclass`) — единственный класс в проекте. Он только называет поля записи,
ни наследования, ни интерфейсов нет.


## Возможные ошибки и их обработка

| Ситуация                                        | Реакция программы                                                              |
|-------------------------------------------------|--------------------------------------------------------------------------------|
| Пункт меню не из списка                         | сообщение «нет такого пункта меню», меню показывается снова                    |
| Вместо числа введён текст                       | «нужно ввести целое число», вопрос повторяется                                 |
| Число вне допустимого диапазона (−5, 400, 99)   | сообщение с границами, вопрос повторяется                                      |
| Пустая строка в обязательном поле               | «строка не должна быть пустой», вопрос повторяется                             |
| Неверная дата (`32.13.2026`, `abc`)             | подсказка о формате ДД.ММ.ГГГГ / ГГГГ-ММ-ДД, вопрос повторяется                |
| Файла данных нет                                | старт с пустым календарём                                                      |
| Файл данных пустой                              | старт с пустым календарём                                                      |
| Файл повреждён (не JSON)                        | копия сохраняется как `events.bak`, старт с пустым календарём, предупреждение  |
| Часть записей в файле некорректна               | эти записи пропускаются с указанием номера, остальные загружаются              |
| Не удалось записать файл (нет прав, диск)       | сообщение об ошибке, программа продолжает работать                             |
| Ctrl+C / Ctrl+D                                 | штатный выход с сохранением данных                                             |

Запись в файл идёт через временный файл с последующей заменой, поэтому сбой во время
сохранения не портит прежние данные.
